我的第一篇博客：Hello World

2026-09-20 随笔

欢迎来到我的博客！这是我的第一篇文章。

每个程序员的旅程都从 Hello World 开始。这个博客是我学习 Web 开发后做的第一个项目，虽然它现在还很简陋，但这只是一个开始。

为什么要做这个博客？

作为一名信息工程专业的大二学生，我意识到光靠课堂上学的东西是不够的。我想通过实际动手做项目来：

  • 巩固课堂上学到的知识
  • 学习课堂上没有教的实用技能
  • 培养解决实际问题的能力
  • 建立自己的作品集

我学到了什么？

在搭建这个博客的过程中，我学习了：

  • HTML 的基本结构和常用标签
  • CSS 的盒模型、Flexbox 布局和响应式设计
  • JavaScript 的基础语法和 DOM 操作
  • Git 版本控制的基本操作
  • 使用 GitHub Pages 部署静态网站

下一步计划

这个博客还有很多可以改进的地方。接下来我打算：

  1. 用 JSON 文件管理文章数据，实现动态加载
  2. 添加文章搜索功能
  3. 完善文章分类和标签筛选
  4. 优化移动端体验

如果你也是刚开始学习编程的同学，希望这个博客能给你一些参考。一起加油！
